# XBox DNS Toggle v1.0

**Переключатель Xbox DNS (176.99.11.77) + DoH для Windows 10/11**

## 📱 Что делает скрипт

- **Пункт 1**: Включает Xbox DNS (`176.99.11.77`, `80.78.247.254`) + DoH (`https://xbox-dns.ru/dns-query`)
- **Пункт 2**: Отключает Xbox DNS, возвращает DHCP от роутера
- **Пункт 3**: Показывает все сетевые адаптеры
- **Пункт 4**: Полная проверка DNS + DoH статус
- **Пункт 5**: Выход

## ⚠️ Важные требования

- **Обязательно запускать от администратора**
- Автоопределение: **Ethernet 2**, **Wi-Fi**, **Ethernet**
- **Windows**: ищет "Connected" в списке адаптеров
- DoH применяется **глобально** для всей системы
